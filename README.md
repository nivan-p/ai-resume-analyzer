# AI-Powered Resume Analyzer & Interview Preparation Platform

An intelligent full-stack web application that helps candidates improve their interview readiness using Generative AI.

## Features

- Resume Parsing & Skill Extraction
- AI-Powered Skill Gap Analysis
- Job Description Matching
- Personalized Interview Question Generation
- Technical & Behavioral Interview Preparation
- ATS-Friendly Resume Generation
- Secure JWT Authentication
- Dynamic PDF Resume Generation

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Gemini API
- Puppeteer
